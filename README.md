# Codex Game Prototype

A tiny Unity starter project for an Appel-style 2D platformer.

## Included
- Home screen with a play button.
- Tutorial level generated at runtime.
- Player movement and jumping.
- Platforms, spikes, and a finish goal.

## Controls
- Move: A / D or Arrow Keys
- Jump: Space / W / Up Arrow
- Return to menu: Escape

Open `Assets/Scenes/Main.unity` in Unity 2022.3 LTS or newer and press Play.
